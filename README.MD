# Express.js HTML File Methods

This project covers **three methods of serving HTML files in Express.js**.

## 📌 Methods Covered

### 1. `res.send()`

Used to send HTML content directly as a response.

### 2. `res.sendFile()`

Used to send an HTML file from the computer to the browser.

### 3. `express.static()`

Used to serve static files such as HTML, CSS, JavaScript, and images from a `public` folder.


## 🚀 Run the Project

Install Express:

```bash
npm install express
```

Start the server:

```bash
node app.js
```

Open in the browser:

```text
http://localhost:3000
```
